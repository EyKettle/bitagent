# 应用 State

`createState()` 创建真实定义环境，不承担执行调度、资源清理或值序列化。
定义由同源编译产物和实际原生绑定发布，不接受手填类型字符串或伪造回调。

[Source 与 Session](compiler.md) · [Jobs](jobs.md)

## 观察与移除

`definitions` 与 `snapshot()` 返回不可替换的结构视图；`find(name)` 定位当前定义。
`value(definition)` 读取原始绑定，保持对象/函数身份；纯类型没有运行值，声明的 undefined 则是合法运行值。
`aliases(object)` 按当前绑定值寻找同一对象或函数，不返回旧的反向缓存。

`remove(...definitions)` 先验证全部真实当前句柄，再精确移除；重复句柄只移除一次。
外来、过期或伪造句柄拒绝；移除名字不关闭对象、Job 或模块资源。
结构增删推进 revision，普通赋值或对象修改不改变结构版本。

## 实际发布

输入的纯类型在发布准入时可见；原生提升的 var/function、已完成的声明及部分解构初始化沿实际执行发布。
TDZ 中尚未初始化的名字不伪造为 undefined。
输入抛错仍结束独占发布，保留已发生的绑定/结构变化及原异常；不承诺回滚。
后续输入使用当前定义及其原始固定类型，旧句柄或旧实现引用不被新同名声明替换。
