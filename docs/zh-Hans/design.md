## 脚本控制台

用户编写一段类型安全的 TypeScript 脚本，BitAgent 执行它。

应用启动后为持续运行的实例，不会随一次性脚本的结束而终止。

### 两个核心对象

- **应用实例**：BitAgent 启动的应用程序
- **运行脚本**：正在运行的用户脚本

### 显式清理

BitAgent 会储存所有创建过的函数、变量，不会替用户清理。

BitAgent 提供一套 API 供用户手动管理已定义资源。

也可以通过同样的 API 编写自动化的清理，以便适应流程需求。

## 没有 Agent

BitAgent 没有一个拥有记忆、拥有所有工具、拥有完整上下文的全能 LLM 实体。

LLM 仅作为一个用于生成文本和进行基础推理的工具。

## 封装代码即技能

技能不是文档，技能只是一个具名流程。
它是一个封装为普通函数或任何形式的控制流。
