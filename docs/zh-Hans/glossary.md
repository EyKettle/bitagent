# 术语

BitAgent 的设计与工程使用以下术语。

[架构总纲][architecture] · [源码组织][organization]

[architecture]: architecture.md
[organization]: source-organization.md

| 术语 | 含义 |
| --- | --- |
| 功能模块 | 围绕相关需求，通过统一契约提供能力的职责单元 |
| 单元模块 | 以不可拆分的完整功能特性为交付边界的模块 |
| 父模块与子模块 | 模块之间的包含关系 |
| 组件 | 在明确接口后封装的一组相关实现 |
| 源码文件 | 语言层面的代码组织单元 |
| 公开契约 | 消费者可依赖的输入、效果、输出与生命周期约定 |
| 国际化 | 支持多种语言的机制 |
| 本地化 | 某种具体语言的表达与资源 |

> [!NOTE]
> 功能分类、交付边界与包含关系是不同维度，没有固定的父子对应关系。
> 文件数量也不决定模块或组件数量。
