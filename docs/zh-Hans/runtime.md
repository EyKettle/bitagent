# 运行时设计

Core 的作业与执行范围统一管理流程，宿主适配负责外部操作及清理。

[架构总纲][architecture]

[architecture]: architecture.md

## Core 作业

Core 持有应用执行根、作业身份、启动方式、状态和结果，公开协程与作业契约独立于内核操作类型。
协程通过 Core 原语产生合法挂起点；子作业失败按 Core 的等待契约传播，不以内核默认连带失败代替。

## 结束与清理

执行范围负责自有子作业收束，相应资源完成清理后才提交作业终态。
观察状态不隐式等待；执行终态与业务成败分开，套件根据返回值验收业务结果。

宿主适配连接取消通知、实际操作结束和清理完成，不把 Promise 桥接交给业务调用者。
停止等待或发出 abort 不代表外部操作已经结束。
